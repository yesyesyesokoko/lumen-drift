Lumen Drift is a neon space arcade game: fly a lone light-ship through drifting meteors, blast chasers, weavers and turrets, chain kills into a combo multiplier, and pick up shield, spread-shot and slow-field orbs to survive wave after wave. All art is drawn in code and all sound is synthesized live; the game is plain static files and plays fully offline.

## Run it

```sh
python3 -m http.server --directory game 8080
```

Then open http://localhost:8080 in a desktop browser. Move with the mouse or WASD / arrow keys, fire is automatic, Space dashes (brief invulnerability), P pauses, M mutes, R restarts from the game-over screen.
